# Brand Launch Tile — analytic rubric

| Criterion | Outcome | 1 Beginning | 2 Developing | 3 Secure | 4 Extending |
|---|---|---|---|---|---|
| Audience and message | 1.4 / 4.4 | The audience or message is difficult to identify. | A recognizable message only partly fits the audience. | A clear message and action fit the named audience and brief. | Testing evidence shows precise audience control and purposeful revision. |
| Design principles | 4.1 | Elements compete and relationships appear accidental. | Some alignment, hierarchy and proximity help organization. | Alignment, contrast, hierarchy and spacing create a clear reading path. | The layout uses restraint and every relationship supports the message. |
| Colour and typography | 4.1 / 4.3 | Colour or type choices reduce readability or consistency. | A palette and type pair exist but roles remain uneven. | A limited legible palette and repeatable type roles communicate the brand voice. | Colour and type remain distinctive, accessible and flexible across formats. |
| Photoshop craft and output | 4.4 / 4.5 | The file is destructive, disorganized or exported incorrectly. | Basic layers and export settings work with minor issues. | Named editable layers, masks and correct 1080 sRGB export support revision and delivery. | The file structure and output checks anticipate future adaptations. |
| Process and rationale | 1.3 connection | Evidence or reasons are missing. | Evidence shows completion; reasons mainly describe choices. | Checkpoint, source log and rationale connect decisions to the brief. | Evidence shows audience testing, focused iteration and transferable judgement. |

Teacher confirms achievement after inspecting the editable/process evidence and defence.
