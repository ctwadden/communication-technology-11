# COM11 graphic design — review package

Students learn design principles, colour and typography with actual campaign examples, apply them in twelve small Photoshop labs, then plan and create an approved real school/community message. The planning route now uses the free MIT-licensed Excalidraw browser editor for mood boards; students install nothing and need no account for this lab. Keep Photoshop for two alternative ad layouts, a reader test and a justified revision.
