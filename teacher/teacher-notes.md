## Three-class route

### Class 1: Establish the brand system

- 0–8: Run a five-second gallery test, then repair the weak flyer without changing a single word.
- 8–20: Explain: A brand is a repeatable communication system. Hierarchy orders attention; alignment and proximity create relationships; palette and typography establish a consistent voice.
- 20–35: Model the first three named steps and stop after each expected result.
- 35–60: Guided production/inquiry; use the warning and repair fields.
- 60–67: Checkpoint: Annotated brief, two thumbnails and an editable style tile are complete; every colour and type role can be explained using the audience.
- 67–70: Exit: Which decision is doing the most communication work, and what evidence supports that claim?

### Class 2: Build the launch graphic

- 0–8: Compare readable and unreadable text-over-image examples; locate the value conflict and busiest region.
- 8–20: Explain: The image creates subject and mood while type supplies precise meaning. Crop and tonal control reserve space so both systems can perform their jobs.
- 20–35: Model the first three named steps and stop after each expected result.
- 35–60: Guided production/inquiry; use the warning and repair fields.
- 60–67: Checkpoint: A peer can identify the headline, key detail and action in five seconds; all image, type and mark roles remain editable.
- 67–70: Exit: What did you change in the photograph so the words could do their job?

### Class 3: Test, transfer and deliver

- 0–8: Conduct a silent five-second test before any designer explains the work.
- 8–20: Explain: A brand system proves itself through transfer. Some spatial decisions must change with format, while palette, type roles, tone and identity remain recognizably consistent.
- 20–35: Model the first three named steps and stop after each expected result.
- 35–60: Guided production/inquiry; use the warning and repair fields.
- 60–67: Checkpoint: Style tile, square launch piece, adaptation, audience-test evidence, before/after revision, source log and rationale are complete.
- 67–70: Exit: What changed between formats, what stayed consistent and why?

## Assessment boundary

The website records practice only. Confirm achievement by inspecting the required evidence, asking the defence questions and using the rubric.
