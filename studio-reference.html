1Day 1 · 70 minutes

Establish the brand system

How can visual decisions make one message recognizable before a logo is explained?

Open slides
HOOK

Run a five-second gallery test, then repair the weak flyer without changing a single word.

TEACH

Client brief, audience, hierarchy, alignment, proximity, contrast, accessible colour, type roles, repetition and wordmark construction.

HOW IT ACTUALLY WORKS

A brand is a repeatable communication system. Hierarchy orders attention; alignment and proximity create relationships; palette and typography establish a consistent voice.

MATERIALS
Three client briefsWeak flyerStyle-tile templateContrast labType-pairing support

Annotate the client brief

LOCATION · Client card
EXPECTED RESULTAudience, purpose, required message, tone words and constraints are marked
WHY THIS MATTERSThe brief supplies reasons for every design decision
COMMON ERRORChoosing only by favourite image
REPAIRName the audience need first
2

Create two composition thumbnails

LOCATION · Paper or template
EXPECTED RESULTTwo distinct reading paths show headline, image and action zones
WHY THIS MATTERSAlternatives prevent the first idea becoming automatic
COMMON ERRORDrawing decoration instead of hierarchy

Repair the weak flyer

LOCATION · Design decision laboratory
EXPECTED RESULTHeadline, detail and action read in a deliberate order
WHY THIS MATTERSComparison makes principles visible

LOCATION · Character panelHOTKEY T

2Day 2 · 70 minutes

Build the launch graphic

How can photograph and type share one reading path?

Open slides
HOOK

Compare readable and unreadable text-over-image examples; locate the value conflict and busiest region.

TEACH

1080 square setup, Place Embedded, Smart Objects, crop, subject position, masks, clipped Curves, safe area, type hierarchy and mark placement.

HOW IT ACTUALLY WORKS

The image creates subject and mood while type supplies precise meaning. Crop and tonal control reserve space so both systems can perform their jobs.

3Day 3 · 70 minutes

Test, transfer and deliver

Does the system survive a new format and a real audience test?

Open slides
HOOK

Conduct a silent five-second test before any designer explains the work.

TEACH

Audience evidence, targeted revision, consistency audit, A4 adaptation, alternate-audience transfer, source logging, export specifications and rationale.

HOW IT ACTUALLY WORKS

A brand system proves itself through transfer. Some spatial decisions must change with format, while palette, type roles, tone and identity remain recognizably consistent.

Three-class assignment sprint

Brand Launch Tile

The product grows across three classes. Students do not repeat one layout: they establish a system, apply it to a launch graphic, then prove the system can survive audience testing and a new format.

1. Class A · Decode and direct

Choose a client, identify audience and message, repair the weak-flyer principles, then complete the palette and type hierarchy on the style tile.

2. Class B · Build the message

Create the 1080 × 1080 launch graphic with an editable image, clear hierarchy, restrained mark and consistent brand system.

3. Class C · Test and deliver

Run a silent five-second audience test, revise the clearest mismatch, confirm sRGB/size and submit the rationale plus process evidence.

Pathways that add real complexity

Tier 1 · Directed system

Use the supplied grid, recommended type pairing and accessible palette to create the complete style tile and launch graphic.

Tier 2 · Designer-controlled system

Create an original wordmark, palette and layout, then adapt the launch graphic to A4 without losing hierarchy.

Tier 3 · Audience transfer

Reposition the same brand for a second audience or campaign moment and justify what remains consistent and what changes.

Retrieval check

Can you explain the decisions?

1. What establishes the order in which information is noticed?

Answer: Hierarchy creates the reading order.

2. Why use proximity?

Answer: Items placed near one another appear related.

3. What is the strongest reason to choose a colour?

Answer: Colour choices need an audience and communication reason.

4. Which file is the web delivery product?

Answer: The PNG is the web export; the PSD preserves production.

5. What does a five-second test measure?

Answer: It checks what the audience notices before an explanation changes their response.
