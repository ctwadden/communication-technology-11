Brand Launch Tile

Choose a fictional client and create a repeatable brand system: style tile, 1080 x 1080 launch graphic and a second-format adaptation. Support changes the scaffold; extension changes the design problem.

Assignment duration: three full 70-minute classes: establish a brand system, build the launch piece, then test and transfer it to a second format.

Three-class sprint

Class A · Decode and directChoose a client, identify audience and message, repair the weak-flyer principles, then complete the palette and type hierarchy on the style tile.
Class B · Build the messageCreate the 1080 × 1080 launch graphic with an editable image, clear hierarchy, restrained mark and consistent brand system.
Class C · Test and deliverRun a silent five-second audience test, revise the clearest mismatch, confirm sRGB/size and submit the rationale plus process evidence.

Pathways that add real complexity

Tier 1Directed systemUse the supplied grid, recommended type pairing and accessible palette to create the complete style tile and launch graphic.
Tier 2Designer-controlled systemCreate an original wordmark, palette and layout, then adapt the launch graphic to A4 without losing hierarchy.
Tier 3Audience transferReposition the same brand for a second audience or campaign moment and justify what remains consistent and what changes.

Required evidence

  1. Annotated client brief and two composition thumbnails
  2. Editable style tile with palette, type roles and original wordmark
  3. Layered 1080 x 1080 launch graphic
  4. A4 or alternate-audience adaptation
  5. Five-second audience-test evidence and before/after revision
  6. Source log and four-sentence design rationale

Foundation checkpoints

Day 1Establish the brand systemAnnotated brief, two thumbnails and an editable style tile are complete; every colour and type role can be explained using the audience.
Day 2Build the launch graphicA peer can identify the headline, key detail and action in five seconds; all image, type and mark roles remain editable.
Day 3Test, transfer and deliverStyle tile, square launch piece, adaptation, audience-test evidence, before/after revision, source log and rationale are complete.
