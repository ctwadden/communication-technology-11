Communication Technology 11 · Week 1 · Part 3

Test + adapt the system

Class 2 · 50–70 + Class 3 · 0–40 · Follow every step in order. Do not skip the expected-result check.

Before you begin: Open the student ZIP, place it in a named course folder, preserve the originals, and save a versioned working file before editing.
Linear build

Do → inspect → repair

Every visible outcome is taught below. A step is not finished until your screen or evidence matches the expected result.

Step 12

Place the wordmark

Smart Object or editable group

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Mark appears once at a stable scale and position
Why this matters
Identity supports rather than replaces the message
Warning — common failure
Making the logo the largest element
Repair it
Return to the hierarchy order
Step 13

Run phone-size and grayscale tests

Fit Screen plus temporary Black & White

Hotkey: Cmd/Ctrl 0

Expected result
Hierarchy survives reduced size and without hue
Why this matters
Real viewing exposes fragile contrast
Warning — common failure
Judging only at 200 percent
Repair it
Test at Fit Screen and actual phone size
Step 14

Save the layered launch evidence

02_working and 04_evidence

Hotkey: Cmd/Ctrl S

Expected result
PSD screenshot includes image, mask, adjustments, type and mark
Why this matters
Process evidence makes the design decisions assessable
Warning — common failure
Submitting a flattened mock-up
Repair it
Capture the actual Layers panel
Step 15

Collect silent audience evidence

Five-second test

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Reviewer records first message, mood and focal element
Why this matters
Received communication tests the design claim
Warning — common failure
Explaining before testing
Repair it
Show silently, then record exact responses
Step 16

Choose one high-value revision

Rubric plus test evidence

Hotkey: No required shortcut — use the named menu or panel.

Expected result
One hierarchy, contrast or spacing mismatch is named
Why this matters
Focused revision protects the system
Warning — common failure
Redesigning everything after one opinion
Repair it
Repair the clearest repeated mismatch
Student check

Answer before moving on

Checkpoint: Style tile, square launch piece, adaptation, audience-test evidence, before/after revision, source log and rationale are complete.
Support

Adapt only the hierarchy and spacing; keep the approved palette, type roles and mark fixed.

Transfer

Reposition the brand for a second audience and defend which system elements needed to change.
