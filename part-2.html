Correct square canvas opens with guides

Format shapes layout decisions from the start
Warning — common failure

Step 9

Place and crop the photograph

File > Place Embedded > Free Transform

Hotkey: Cmd/Ctrl T

Expected result
Subject is clear and a calm type zone remains
Why this matters
Composition must make room for language
Warning — common failure
Covering the busiest detail with text
Repair it
Move or crop the image before adding boxes
Step 10

Control the text-safe value

Clipped Curves with mask

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Type zone gains contrast without flattening the whole image
Why this matters
Local value is more controlled than global opacity
Warning — common failure
Darkening everything
Repair it
Clip and mask the adjustment
