Brand Foundations

Graphic design is controlled communication: every visual relationship should help a named audience receive a particular message in a deliberate order.

Pacing decision: three full 70-minute classes: establish a brand system, build the launch piece, then test and transfer it to a second format.

Your ten-minute pre-read

The expert frame

Hierarchy is the order of attention. Size, weight, contrast, position and space should agree about what comes first.

Proximity creates meaning by grouping related information; alignment creates invisible structure across the composition.

A brand is a repeatable system of decisions, not merely a logo. Palette, type, imagery, tone and mark must behave consistently.

Contrast is both expressive and functional. Body text should meet the 4.5:1 target; large text can meet 3:1, but ratios do not replace visual judgement.

The five-second test measures received communication before the designer explains their intention. A mismatch is evidence for revision, not failure.

Questions students may ask

Can I use more fonts or colours?Only if each addition has a distinct communication job. Week 1 rewards control and repeatability, not decoration.
Is the logo the brand?No. The mark identifies; the brand system creates a consistent experience and expectation.
Why test for only five seconds?A launch graphic must establish its message and reading order quickly. The test exposes hierarchy without an explanation biasing the viewer.
Your through-line: Return every answer to mechanism → visible or sourced evidence → consequence. Students should hear you explain why a decision works, not only where a control is located.
Assignment map

What the product actually requires

1. Class A · Decode and direct

Choose a client, identify audience and message, repair the weak-flyer principles, then complete the palette and type hierarchy on the style tile.

2. Class B · Build the message

Create the 1080 × 1080 launch graphic with an editable image, clear hierarchy, restrained mark and consistent brand system.

3. Class C · Test and deliver

Run a silent five-second audience test, revise the clearest mismatch, confirm sRGB/size and submit the rationale plus process evidence.

Pathways that add real complexity

Tier 1 · Directed system

Use the supplied grid, recommended type pairing and accessible palette to create the complete style tile and launch graphic.

Tier 2 · Designer-controlled system

Create an original wordmark, palette and layout, then adapt the launch graphic to A4 without losing hierarchy.

Tier 3 · Audience transfer

Reposition the same brand for a second audience or campaign moment and justify what remains consistent and what changes.

Assessment boundary: F-P-CT11-4-4 | Brand Launch Tile is recommended as formative or revision-eligible. Confirm achievement by inspecting the required evidence; the website checklist and quiz never assign mastery.

Day 1

Establish the brand system

Say this to launch:
“Today’s puzzle is How can visual decisions make one message recognizable before a logo is explained? Before we name tools or concepts, commit to one observation and the evidence that made you notice it.”
0–8 · HOOK

Run a five-second gallery test, then repair the weak flyer without changing a single word.

8–20 · EXPERT EXPLANATION

A brand is a repeatable communication system. Hierarchy orders attention; alignment and proximity create relationships; palette and typography establish a consistent voice.

20–35 · MODEL

Demonstrate the first three actions. After each one, point to the visible result and explain why the choice matters.

35–60 · GUIDED WORK

Release students into the remaining steps. Pause once for a partner evidence check.

60–67 · CHECKPOINT

Annotated brief, two thumbnails and an editable style tile are complete; every colour and type role can be explained using the audience.

67–70 · EXIT

Which decision is doing the most communication work, and what evidence supports that claim?

Board plan

Question: How can visual decisions make one message recognizable before a logo is explained?
Key language: Client brief, audience, hierarchy, alignment, proximity, contrast, accessible colour, type roles, repetition and wordmark construction.
Mechanism: A brand is a repeatable communication system. Hierarchy orders attention; alignment and proximity create relationships; palette and typography establish a consistent voice.
Evidence due: Annotated brief, two thumbnails and an editable style tile are complete; every colour and type role can be explained using the audience.

Misconceptions to intercept

If you see:

Choosing only by favourite image

Say / do:

Name the audience need first

If you see:

Drawing decoration instead of hierarchy

Say / do:

Use only rectangles and labels

If you see:

Changing the copy

Say / do:

Keep every word and change relationships only

Cold-call question: Which decision is doing the most communication work, and what evidence supports that claim?
Listen for: a specific mechanism or design decision, evidence from the work, and a reason—not merely a description.
Day 2

Build the launch graphic

Say this to launch:
“Today’s puzzle is How can photograph and type share one reading path? Before we name tools or concepts, commit to one observation and the evidence that made you notice it.”
0–8 · HOOK

Compare readable and unreadable text-over-image examples; locate the value conflict and busiest region.

8–20 · EXPERT EXPLANATION

The image creates subject and mood while type supplies precise meaning. Crop and tonal control reserve space so both systems can perform their jobs.

20–35 · MODEL

Demonstrate the first three actions. After each one, point to the visible result and explain why the choice matters.

35–60 · GUIDED WORK

Release students into the remaining steps. Pause once for a partner evidence check.

Board plan

Question: How can photograph and type share one reading path?
Key language: 1080 square setup, Place Embedded, Smart Objects, crop, subject position, masks, clipped Curves, safe area, type hierarchy and mark placement.
Mechanism: The image creates subject and mood while type supplies precise meaning. Crop and tonal control reserve space so both systems can perform their jobs.
Evidence due: A peer can identify the headline, key detail and action in five seconds; all image, type and mark roles remain editable.

Day 3

Test, transfer and deliver

Say this to launch:
“Today’s puzzle is Does the system survive a new format and a real audience test? Before we name tools or concepts, commit to one observation and the evidence that made you notice it.”
0–8 · HOOK

Conduct a silent five-second test before any designer explains the work.

8–20 · EXPERT EXPLANATION

A brand system proves itself through transfer. Some spatial decisions must change with format, while palette, type roles, tone and identity remain recognizably consistent.

20–35 · MODEL

Demonstrate the first three actions. After each one, point to the visible result and explain why the choice matters.

35–60 · GUIDED WORK

Release students into the remaining steps. Pause once for a partner evidence check.

60–67 · CHECKPOINT

Style tile, square launch piece, adaptation, audience-test evidence, before/after revision, source log and rationale are complete.

67–70 · EXIT

What changed between formats, what stayed consistent and why?

Board plan

Question: Does the system survive a new format and a real audience test?
Key language: Audience evidence, targeted revision, consistency audit, A4 adaptation, alternate-audience transfer, source logging, export specifications and rationale.
Mechanism: A brand system proves itself through transfer. Some spatial decisions must change with format, while palette, type roles, tone and identity remain recognizably consistent.
Evidence due: Style tile, square launch piece, adaptation, audience-test evidence, before/after revision, source log and rationale are complete.

Misconceptions to intercept

If you see:

Say / do:

If you see:

Say / do:

Repair the clearest repeated mismatch

If you see:

Stretching the square design

Say / do:

Recompose for the new format

Cold-call question: What changed between formats, what stayed consistent and why?
Listen for: a specific mechanism or design decision, evidence from the work, and a reason—not merely a description.

Evidence and feedback

1. Annotated client brief and two composition thumbnails
2. Editable style tile with palette, type roles and original wordmark
3. Layered 1080 x 1080 launch graphic
4. A4 or alternate-audience adaptation
5. Five-second audience-test evidence and before/after revision
6. Source log and four-sentence design rationale
