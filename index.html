1Day 1 · 70 minutes

A message needs an order

What should the audience notice first?

Open slides
HOOK

View four launch graphics for five seconds each. Record the first message, intended audience and strongest visual clue.

TEACH

Brief, audience, hierarchy, alignment, contrast, proximity, repetition and negative space.

HOW IT ACTUALLY WORKS

A layout controls attention by creating differences and relationships. Hierarchy establishes order; alignment and proximity show which elements belong together.

MATERIALS
Weak flyer PNGPrinciples labClient brief cards
Video cue · Four artists use the same images13:09; teacher-selected hook · Preview and show one comparison only

Read the message before styling

LOCATION · Weak flyer copy sheet
EXPECTED RESULTHeadline, essential detail and call to action are marked
WHY THIS MATTERSContent priority must come before decoration
COMMON ERRORStarting with colours and effects
REPAIRRank the information 1, 2 and 3 first
2

Choose one alignment system

LOCATION · Photoshop guides or a paper thumbnail grid
EXPECTED RESULTMost edges share a consistent left, centre or grid line
WHY THIS MATTERSAlignment makes separate elements feel related
COMMON ERRORCentred type plus random left-aligned details
REPAIRCommit to one main axis
3

Create visible hierarchy

LOCATION · Type size, weight, placement and contrastHOTKEY T
EXPECTED RESULTThe headline reads first, essential detail second and action third

Group related information

LOCATION · Move layers and spacingHOTKEY V

COMMON ERRORUsing boxes around every line

Limit contrast to useful moments

LOCATION · Colour and scale decisions

2Day 2 · 70 minutes

Audience becomes colour

What should the palette help the audience feel and do?

Open slides
HOOK

Match three anonymous palettes to the three client briefs, then defend the match without using personal preference.

TEACH

Photoshop workspace, named layers, Smart Objects, RGB, hue, value, saturation, contrast, harmony and cultural context.

HOW IT ACTUALLY WORKS

Colour creates difference, association and legibility. A limited palette works when contrast supports reading and the associations fit the audience and context.

3Day 3 · 70 minutes

Typography gives the brand a voice

How can type sound different before anyone reads it?

Open slides
HOOK

Show the same message in four type treatments. Students assign each to a client and cite shape, weight, spacing or case as evidence.

TEACH

Display versus text type, pairing by contrast, readability, scale, weight, leading, tracking, case and semantic hierarchy.

HOW IT ACTUALLY WORKS

Typography carries language and visual form at the same time. A type system assigns repeatable roles so the audience can predict how to read the message.

MATERIALS
Type pairing sheetMessage lock-up templateStyle-tile PSD
1

Choose one display and one text typeface

LOCATION · Character panelHOTKEY T
EXPECTED RESULTThe pair differs clearly but does not compete
WHY THIS MATTERSUseful contrast creates distinct roles
COMMON ERRORChoosing two decorative faces
REPAIRKeep one voice expressive and one quiet
2

Set the required client line

LOCATION · Type tool; separate text layersHOTKEY T
EXPECTED RESULTHeadline and essential detail remain editable
WHY THIS MATTERSSeparate layers preserve control
COMMON ERRORTyping every line on one layer
REPAIRUse one layer per information role
3

Create hierarchy with size and weight

LOCATION · Character panel
EXPECTED RESULTHeadline leads; supporting detail remains readable
WHY THIS MATTERSScale and weight establish reading order
COMMON ERRORUsing effects to force hierarchy
REPAIRRemove effects and solve order with type first
4

Adjust spacing

LOCATION · Tracking and leading controlsHOTKEY Option/Alt + arrow keys
EXPECTED RESULTLetters and lines have even optical space
WHY THIS MATTERSSpacing affects voice and readability
COMMON ERRORTight tracking on small body text
REPAIRReset body tracking and add comfortable leading
5

Align the lock-up

LOCATION · Move tool and guidesHOTKEY V
EXPECTED RESULTType edges connect to the style-tile grid
WHY THIS MATTERSTypography belongs to the same layout system
COMMON ERROREyeballing every position
REPAIRSnap the text to guides
6

Run the blur and distance test

LOCATION · Zoom out or step away from screenHOTKEY Cmd/Ctrl 0
EXPECTED RESULTThe headline remains identifiable before smaller copy
WHY THIS MATTERSHierarchy must survive real viewing conditions
COMMON ERRORJudging only at 200% zoom
REPAIRTest at Fit Screen and projector distance
CHECKPOINT
A peer can identify the client and read the required line without explanation; the style tile shows repeatable Headline and Detail roles.
SUPPORT

Use one of five pre-tested system-font pairings.

CORE EXIT

Name one typography choice that communicates a brand adjective before the words are read.

EXTENSION

Create a custom wordmark by adjusting spacing or one letterform while keeping the type editable.

Images and words share one system

How can a photograph support the message without competing with it?

HOOK

TEACH

Place Embedded, image crop, subject placement, layer masks, adjustment layers, text safe area and simple word/shape mark.

HOW IT ACTUALLY WORKS

The image supplies subject and mood; typography supplies precise meaning. Cropping, masks and tonal control reserve a clear reading path for both.

Three-class assignment sprint

Brand Launch Tile

The full foundation sequence is five classes. The assessed anchor product is deliberately scoped to three production classes and can be compressed to two by combining the final test with Class B.

1. Class A · Decode and direct

Choose a client, identify audience and message, repair the weak-flyer principles, then complete the palette and type hierarchy on the style tile.

2. Class B · Build the message

Create the 1080 × 1080 launch graphic with an editable image, clear hierarchy, restrained mark and consistent brand system.

3. Class C · Test and deliver

Run a silent five-second audience test, revise the clearest mismatch, confirm sRGB/size and submit the rationale plus process evidence.

Retrieval check

Can you explain the decisions?

1. What establishes the order in which information is noticed?

Answer: Hierarchy creates the reading order.

2. Why use proximity?

Answer: Items placed near one another appear related.

3. What is the strongest reason to choose a colour?

Answer: Colour choices need an audience and communication reason.

4. Which file is the web delivery product?

Answer: The PNG is the web export; the PSD preserves production.

5. What does a five-second test measure?

Answer: It checks what the audience notices before an explanation changes their response.
