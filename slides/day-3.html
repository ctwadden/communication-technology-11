CT11 · Mechanism

How it actually works

A brand system proves itself through transfer. Some spatial decisions must change with format, while palette, type roles, tone and identity remain recognizably consistent.

CT11 · Pathways

Support and extension

Support

Adapt only the hierarchy and spacing; keep the approved palette, type roles and mark fixed.

Extension

Reposition the brand for a second audience and defend which system elements needed to change.

Brand Foundations
Speaker notes

Support changes access to the same essential skill. It does not hide the target technique.

CT11 · Evidence

Checkpoint and exit

Checkpoint

Style tile, square launch piece, adaptation, audience-test evidence, before/after revision, source log and rationale are complete.

Exit question

What changed between formats, what stayed consistent and why?

Brand Foundations
Speaker notes

Inspect the evidence rather than accepting a completion check. Use the exit response to decide tomorrow's two-minute retrieval prompt.
