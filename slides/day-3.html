CT11 · Mechanism

How it actually works

Typography carries language and visual form at the same time. A type system assigns repeatable roles so the audience can predict how to read the message.

CT11 · Pathways

Support and extension

Support

Use one of five pre-tested system-font pairings.

Extension

Create a custom wordmark by adjusting spacing or one letterform while keeping the type editable.

Brand Foundations
Speaker notes

Support changes access to the same essential skill. It does not hide the target technique.

CT11 · Evidence

Checkpoint and exit

Checkpoint

A peer can identify the client and read the required line without explanation; the style tile shows repeatable Headline and Detail roles.

Exit question

Name one typography choice that communicates a brand adjective before the words are read.

Brand Foundations
Speaker notes

Inspect the evidence rather than accepting a completion check. Use the exit response to decide tomorrow's two-minute retrieval prompt.
