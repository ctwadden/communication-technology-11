CT11 · Mechanism

How it actually works

Colour creates difference, association and legibility. A limited palette works when contrast supports reading and the associations fit the audience and context.

CT11 · Pathways

Support and extension

Support

Start from one of three supplied accessible palettes and change only the accent.

Extension

Test the palette in grayscale and adjust it so the hierarchy survives without hue.

Brand Foundations
Speaker notes

Support changes access to the same essential skill. It does not hide the target technique.

CT11 · Evidence

Checkpoint and exit

Checkpoint

Each colour has a job; body text meets the contrast target; the palette can be explained using the audience and brief adjectives.

Exit question

Which palette colour carries the brand voice, and which colour protects legibility?

Brand Foundations
Speaker notes

Inspect the evidence rather than accepting a completion check. Use the exit response to decide tomorrow's two-minute retrieval prompt.
