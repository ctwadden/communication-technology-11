CT11 · Mechanism

How it actually works

A brand is a repeatable communication system. Hierarchy orders attention; alignment and proximity create relationships; palette and typography establish a consistent voice.

Brand Foundations
Speaker notes

Release students after the first guided action. Circulate for the named repairs: Connect each colour to audience and function; Make one expressive and one quiet; Use the client name and one original geometric move.

CT11 · Pathways

Support and extension

Support

Use the supplied grid, one pre-tested palette and one recommended system-font pairing.

Extension

Create a second valid style direction for the same client and compare the audience effect.

Brand Foundations
Speaker notes

Support changes access to the same essential skill. It does not hide the target technique.

CT11 · Evidence

Checkpoint and exit

Checkpoint

Annotated brief, two thumbnails and an editable style tile are complete; every colour and type role can be explained using the audience.

Exit question

Which decision is doing the most communication work, and what evidence supports that claim?

Brand Foundations
Speaker notes

Inspect the evidence rather than accepting a completion check. Use the exit response to decide tomorrow's two-minute retrieval prompt.
